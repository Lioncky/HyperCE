## HyperCE 
> This Project is based on HyperDbg(VT-x)
> 

## Build
> BuildVersion: C++17 & vc142(2019)
> !Attention: This program uses the non-open-source `WinNtEasy` library. 
> To compile it, you must implement all the referenced library components yourself.

## Attach 
> Click the title menu icon and drag to the target program window to attach.
